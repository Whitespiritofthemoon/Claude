## Quick Start (Connect 500+ Apps)

```bash
claude --plugin-dir ./connect-apps-plugin
/connect-apps:setup
```

Get a free API key at [platform.composio.dev](https://platform.composio.dev) to connect Gmail, Slack, GitHub, Notion, and 500+ more apps.

---

## Installation

**Claude.ai:** Click the skill icon → add from marketplace, or upload custom skills directly.

**Claude Code:** Place skills in `~/.config/claude-code/skills/`, verify `SKILL.md` metadata, then launch Claude.

**Via API:** Use the Claude Skills API to integrate skill functionality programmatically.
